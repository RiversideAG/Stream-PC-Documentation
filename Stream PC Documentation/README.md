# Windows Documentation

*Instructions updated for Windows 11 25H2.*

The files in `Windows Documentation` are a reference for how Windows is set up on the RiversideAG stream PC. If there are problems in Windows, you can use them as a resource for diagnosis. Certain parts of this documentation should also be updated as the system is changed, detailed below. Finally, if you need to reinstall Windows for whatever reason, these files give details on how to do that.

*No AI was used in the creation of any of these instructions.*

## Organization

In `Windows Installation.md` you'll find instructions on how to install Windows while preserving your privacy and agency. Crucially, Microsoft's requirement for an online account is circumvented using these instructions. *Microsoft-linked accounts were the root cause of the original installation being accidentally deleted*.

In `Windows Software.md` you'll find a list of software to install. The list is deliberately short so that you can fill it out with what you install. **This document should be updated as more software is installed.** While you don't have to document the settings for each piece of software you install, it can be helpful for software you expect to configure multiple times or had a hard time customizing.

In `Windows Debloating.md` you'll find instructions on how to remove unnecessary software and fix poorly designed configuration options in Windows. This is mostly done through community-authored scripts, making the process very easy. These instructions generally don't need to be changed.

In `Windows Settings.md` you'll find a list of important system settings to set and, when appropriate, the reasons they were set.

*Note that `Windows Settings.md` assumes the instructions in `Windows Debloating.md` have already been followed, which may change some settings.*
